Active Recall Engineering Reference

High-Yield Concepts Engineers Forget Before Interviews

According to the Ebbinghaus forgetting curve, learners lose up to 70% of newly read technical material within 24 hours without active retrieval. Test yourself on these core trade-offs:

1. Write-Through vs. Write-Back Caching

Core Trade-Off: Write-Through updates cache and database synchronously—guaranteeing strong consistency at the cost of higher write latency. Write-Back writes to cache first and flushes asynchronously to the DB, maximizing write throughput while risking data loss if a cache node crashes before flushing.

2. Why Hybrid Search (BM25 + Dense Vector) Beats Pure Vector RAG

Core Trade-Off: Dense embeddings capture semantic intent but struggle with exact SKU codes, function names, or rare acronyms. Combining sparse lexical matching (BM25) with vector similarity via Reciprocal Rank Fusion (RRF) eliminates exact-match blind spots in production retrieval pipelines.

3. Idempotency Keys in Distributed Payment APIs

Core Trade-Off: Network timeouts leave clients unsure if a charge succeeded. Attaching a unique client-generated Idempotency-Key allows the server to deduplicate retried POST requests and return the cached original response without double-charging.

FAQ

Common Questions About Zevru

How is Zevru different from traditional flashcard apps like Anki?

Zevru eliminates manual card creation and overdue review backlogs. AI turns voice dumps or highlighted notes into mutating active-recall prompts, caps daily reviews at 3 high-priority items, and uses a tactile Hold-to-Unblur interface to prevent mindless notification swiping.

How does the Ebbinghaus forgetting curve schedule revisions?

Zevru schedules active recall checkpoints at scientifically spaced intervals (24 hours, 3 days, 7 days, 16 days, and 35 days) and dynamically adapts based on whether you locked in the concept or needed another look.

What is Question Mutation in spaced repetition?

Instead of showing the exact same flashcard text repeatedly, Zevru evolves each prompt across intervals—progressing from Day 1 recognition to Day 3 core recall, Day 7 edge-case application, and Day 21 cross-concept synthesis.
